# Yasir Ismail — Portfolio

A modern, responsive personal portfolio website built with a glassmorphism design aesthetic. Features smooth animations, a typing effect, and a dark-themed UI to showcase projects, skills, and contact information.

## Live Preview

Open `index.html` in any modern browser to view locally.

## Features

- **Glassmorphism UI** — frosted-glass cards, blurred backgrounds, and subtle borders
- **Responsive Design** — fully mobile-friendly layout powered by Bootstrap 5
- **Smooth Scroll & AOS Animations** — scroll-triggered animations via [AOS](https://michalsnik.github.io/aos/)
- **Typing Effect** — animated hero tagline on page load
- **Back to Top Button** — appears on scroll for quick navigation
- **Contact Form** — integrated contact section with social links

## Sections

| # | Section | Description |
|---|---------|-------------|
| 1 | **Home** | Hero area with profile image, CTA buttons, and floating tags |
| 2 | **About** | Work philosophy cards (Discovery, Build, Refine) |
| 3 | **Skills** | Frontend, Backend & Database, and Tools & Others |
| 4 | **Projects** | Featured work — TipTop Furniture, SolarEdge, IMS Pro |
| 5 | **Timeline** | Practical journey and education history |
| 6 | **Contact** | Contact form, email, phone, location, and social links |

## Tech Stack

- **HTML5** / **CSS3** (custom properties, animations, glassmorphism)
- **JavaScript** (ES6+)
- **Bootstrap 5**
- **Font Awesome 6**
- **AOS** (Animate On Scroll)
- **Google Fonts** — Inter & Outfit

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Yasir-Ismail/Portfolio.git
   ```
2. **Open in browser**
   ```bash
   cd Portfolio
   start index.html   # Windows
   open index.html     # macOS
   ```

No build tools or dependencies to install — all libraries are loaded via CDN.
